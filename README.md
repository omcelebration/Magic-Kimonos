# Magic Kimonos

Magic Kimonos Shopify store development repository.

## Structure

- `shopify/` — Shopify theme files
- `docs/` — project notes and planning
- `assets/` — images and media
- `backups/` — theme backups

## Development Workflow

1. Work only on development themes.
2. Preview changes before publishing.
3. Do not edit live theme directly.
